# 라이벌과의 비교 및 검증 기록

## 범위와 근거

요청: 기존 게임을 유지하며 무기·움직임을 라이벌과 비교하고, 사람이 재미있게 플레이할 수 있도록 개선한다. 기존 4개 맵, 게스트/계정, AI 연습, 팀 매칭, 방 코드, 성장 규칙을 유지한다.

- 사용자 영상(2026-10-24, 312.3초): 25/75초 활, 높은 엄폐물 위 이동; 125초 단검과 이동; 225초 RPG가 보이는 장면을 확인했다. 영상의 외형과 동작 종류가 비교 근거다. 원본의 내부 속도·가속도·피해 수치는 측정하지 않았다.
- [Nosniy Games의 공식 Roblox 페이지](https://www.roblox.com/games/17625359962/RIVALS): 1대1~5대5, 먼저 5승하는 FPS 대전을 설명한다. 무기별 정확한 피해·이동 상수는 이 페이지에서 확인되지 않는다.
- [Socket.IO 공식 API](https://socket.io/docs/v4/server-api/): Node.js 온라인 연결 구현 참고.

## 이동 측정

`dist/movement.js`는 브라우저에서 실제로 호출하는 코드이며 별도 시험용 모형이 아니다. 테스트는 전진/달리기, 0.2초와 0.5초의 두 점프, 1초 후 방향 전환을 2초간 실행한다.

| FPS | 최종 X/Z (m) | 점프 최고점 (m) |
|---|---|---|
| 30 | 2.60473 / -17.14704 | 3.15167 |
| 60 | 2.60473 / -17.14704 | 3.15396 |
| 120 | 2.60473 / -17.14704 | 3.15396 |

경로의 최종 위치는 같고, 프레임별로 관찰한 최고점 차이는 약 0.0023m다. 점프 입력 유예 0.1초, 착지 직전 입력 버퍼 0.14초, 벽/낮은 발판/천장, 대각선 속도, 슬라이드 관성도 검사한다. 이 값은 라이벌의 측정값이 아니라 VECTOR의 프레임 간 일관성이다.

## 온라인 조작 일관성 후속 점검

클라이언트의 실제 네트워크 이벤트 함수를 Node.js에서 실행해 다음 두 결함을 먼저 재현하고 수정했다. 브라우저 렌더링이나 사람의 체감을 검증한 것은 아니다.

- 메뉴를 연 동안 서버에서 재장전이 끝나도 클라이언트의 재장전 시간이 남아 있던 문제: 서버 상태와 확인 응답으로 갱신한다.
- 사망 직전 서버가 거절한 무기 전환이 클라이언트에 남던 문제: 요청 번호가 일치하는 최신 확인만 반영하고, 서버 무기로 복원한다.
- 늦은 확인 응답, 아직 확인되지 않은 사격, 전환 직후의 재장전, 부활 중 예전 요청도 검사한다. 탄약을 중복 차감하거나 늦은 요청이 새 무기를 덮어쓰지 않도록 한다.
- 재장전 종료 직후 서버의 다음 50ms 처리 주기 전까지 첫 사격·활 당기기·무기 전환이 잘못 처리되던 문제: 각 동작에서 종료 시각을 즉시 확인한다.

`test/inventory-sync.test.mjs`는 실제 클라이언트 이벤트 코드를 실행하고, `test/socketio.test.mjs`는 실제 Node.js 서버와 Socket.IO 연결에서 확인 응답을 검사한다. 자동 상태 검증이며, 화면 조작 검증은 여전히 아래에 남는다.

## 상대 플레이어 이동 후속 점검

`test/remote-motion.test.mjs`는 실제 원격 아바타 갱신 함수를 Three.js의 위치·회전·관절 객체로 실행한다. 부활한 상대가 사망 위치에서 새 위치까지 이동 보간되는 문제를 먼저 재현했다. 수정 후에는 부활·큰 위치 보정에서 새 위치와 자세를 즉시 반영하고, 평상시 걷기·앉기·방향 전환은 기존 보간을 유지한다. 이는 좌표와 자세의 상태 검증이며 실제 화면 검증은 아니다.

## 완료로 볼 수 없는 부분

현재 세션에서 브라우저 조작 도구를 사용할 수 없어 새 활·RPG·단검 모델, 모션 전환, UI 배치, 터치 입력을 직접 조작·녹화하지 못했다. 자동 검사가 통과해도 사람에게 재미있고 자연스러운지, 영상과 체감이 비슷한지는 증명되지 않는다. 따라서 목표는 계속 진행 상태다.

후속 플레이 검사: HTML 또는 공개 링크에서 AI 봇 연습 1회, 활 당기기/취소/발사, 1~4 전환과 빈 탄창, 달리기→슬라이드→점프→이단 점프, 발밑 RPG, 우클릭 조준/재장전, 2인 온라인 코드 방. 사용감에 대한 사람의 피드백이나 브라우저 검증이 남아 있다.


## 2026-10-25 피격·탄약 업데이트

요청에 따라 기존 맵/이동 체계를 유지하고 다음을 추가했습니다. 총기 50종 + 활/RPG + 근접 20종으로 총 72종이며, 근접 무기별 피해·헤드 배율·도달 거리·공격 속도·이동 속도를 자체 조정했습니다. 마우스 고정 불가 환경도 버튼을 누르지 않고 시점이 움직이며, 화면 가장자리 회전을 제공합니다. 명중 숫자와 빨간 캐릭터 피격 반응, 봇의 총구 불꽃·팔/총 반동을 적용했습니다. 탄약은 무기마다 탄창/예비 수량이 정해져 있고 재장전 시 보존됩니다. 연습장에서만 T로 보충할 수 있습니다.

검증은 실제 클라이언트 함수와 Three.js 모델, 공유 탄약/입력 규칙, Node.js 전투 및 Socket.IO 메시지를 대상으로 합니다. 브라우저 조작 도구가 제공되지 않아 이번 변경의 실제 화면과 손 조작감은 직접 확인하지 못했습니다. 라이벌과 동일한 애니메이션이나 수치를 재현했다는 의미는 아닙니다.
